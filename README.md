# 🌌 Universe Atlas — Explore Beyond

An interactive space exploration website designed to make discovering the universe more engaging through a futuristic interface and immersive visual experiences.

## 🚀 About the Project

**Universe Atlas** is a browser-based space exploration project built to practice frontend development, JavaScript programming, and interactive web design.

The project aims to bring space-related information and visual experiences together in one place.
